# Map one HTML list to one native PowerPoint textbox

V03-01 maps each top-level HTML `ul` or `ol` to one PowerPoint text-bearing
object and each direct `li` to one native bullet or automatic-number paragraph
inside it. Literal marker prefixes and a separate textbox per item would lose
the list's object identity, continuous numbering, unified movement, and native
indent editing. Nested-list behavior is deferred beyond the initial V03-01
acceptance surface.
