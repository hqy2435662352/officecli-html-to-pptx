# Formally support only new-deck Author compilation in V0.2

V0.2 formally supports Author Contract HTML to new editable PPTX compilation.
The constrained OfficeHTML-to-new-PPTX path may remain present for experiments
and internal verification, but it will be marked unsupported and will not be
presented as editing an existing PPTX. This keeps the product promise aligned
with the proven New Deck Creation workflow while master, layout, theme, group,
connector, and complex-table preservation remain unresolved.
