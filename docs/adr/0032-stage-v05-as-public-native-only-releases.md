# Stage V0.5 as public native-only releases before V0.6 fallback

V0.5.1 will be a formal public Author Compiler release that deepens native
text, shape, picture, table, and slide capabilities through the existing
Product Commands, Author Contract, Capability Manifest, Authoring Skill, and
User-Path Acceptance. V0.5.2 is reserved for explicitly authored native chart
semantics, while a general object-local visual fallback is deferred to V0.6;
the hidden PPTX projection seam remains non-product. This sequencing keeps
native PowerPoint semantics as the product differentiator without deleting
existing type-specific compatibility behavior such as the verified SVG picture
fallback. V0.5.1 adds no new PowerPoint object family: connectors, groups,
themes, masters, layouts, diagrams, media, equations, notes, comments,
animations, transitions, and zoom remain deferred.
