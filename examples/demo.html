html-to-pptx

Convert any HTML slide deck into an editable PowerPoint file, pixel-perfectly.

How It Works

1. Measure

A headless browser loads your HTML and measures every visible element: position, size, colors, fonts, borders, and images.

2. Render

Each measurement is mapped to the closest PowerPoint shape: text boxes, picture shapes, and filled rectangles with precise coordinates.

Features

🎨

Pixel-Perfect

DOM measurements ensure positions and sizes match the original HTML layout.

✏️

Fully Editable

Every element becomes a native PPTX shape — text, images, and backgrounds are all editable.

⚡

Fast

Headless Chromium processes complex decks in seconds, not minutes.

What Gets Converted

  • Text with fonts, colors, bold, italic, and alignment
  • Background colors with alpha transparency
  • Rounded corners via OOXML adjustment guides
  • Base64-embedded images as native picture shapes
  • Borders and accent bars as separate shapes
  • CSS text-transform (uppercase, lowercase, capitalize)
  • Hyperlinks preserved on text runs
